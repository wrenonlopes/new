# agent-feed/

Machine-readable competitive state for BIOD's Claude ads agents. Regenerated by
`/competitor-watch`; do not hand-edit mid-campaign.

| File | Consumer | Contract |
|---|---|---|
| `uae-competitive-state.json` | ads agents, planners | Structured snapshot: every competitor's live ads, tone scores, product lines, offers, distribution, plus ranked gaps. Stable `schema_version`. |
| `comedy-briefs.md` | ads agents, creative | Executable ad briefs. Every hook is traced to a line already live on the site, so nothing needs re-clearing. |

## How an ads agent should read this

1. **Check `confidence` before using anything.** Every block carries one.
   `verified` → safe to act on. `documented` → real but second-hand, don't quote as measured.
   `inference` → our read; **never** put it in ad copy or a claim.
2. **Check `collection_status`.** Surfaces marked `not_collected` were blocked, not empty.
   Absence of competitor TikTok data does not mean they have no TikTok.
3. **Obey `prioritised_gaps` order.** Rank 1 is the highest-leverage move, and rank is assigned
   from evidence, not enthusiasm.
4. **The claims policy in the root `README.md` overrides this entire directory.** Three cleared
   claims, no exceptions, jokes included.
5. **Never name a competitor in creative.** Punch at cotton towels and wet wipes — objects, not
   companies.

## Provenance

Ad data comes from the **Meta Ad Library**, queried by `page_ids` — public advertiser
transparency data. That path is reliable. Broad thematic `search_terms` queries return
high-count noise and must not be used to support category-wide claims (we tried; it
returned 1.5M irrelevant results for an emoji query).

Stable page IDs live in `monitoring_handles` — reuse them rather than re-searching by name.

## Regenerating

```bash
/competitor-watch            # full sweep, all surfaces
/competitor-watch ads        # Meta Ad Library only — works even in a restricted session
```

The ads-only path is the one that runs anywhere, because the Ad Library is reached through an
MCP tool rather than the container's network. Everything else (Instagram, TikTok, Amazon,
competitor sites) needs open egress and therefore a local run.
